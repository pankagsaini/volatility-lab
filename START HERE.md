# Volatility Lab Quickstart

Welcome to **Volatility Lab**.

- **Web Dashboard**: Runs 24/7 on Streamlit Cloud with zero laptop dependency.
- **Data Capture**: Runs autonomously via Google Apps Script directly into Google Drive.
- **Local Dashboard**: Double-click `Open Dashboard.cmd` to open the workstation locally.
- **Detailed Documentation**: See [README.md](README.md) for architecture, configuration, and developer setup.
