Cloud recovery without Codex

Keep this file. Your Google collector and Windows task do not run through this chat. No system can promise zero failures. This guide covers common recovery; broker API changes or damaged code may still need technical support.

Start here

  1. Turn on the laptop, connect the internet, and sign in to Google Drive for desktop.
  2. In this same Volatility Lab folder, double-click REPAIR CLOUD SYNC.cmd.
  3. Leave its window open until it finishes. It restores the Windows sync task, retries archive downloads/imports, checks file contents and renews the cleanup receipt.
  4. Read the result. A copy is saved in data/google_archive/repair-report.txt. Local READY does not prove Google is currently capturing.

Repair never deletes your market archives, disables safety checks, or automatically replaces your token. If another sync is running, wait for it to finish and retry. Large backlogs can take time.

Permanent 5TB Cloud Storage

Google Drive captures are stored permanently with zero automatic deletions. Cleanup features and receipt requirements have been removed, giving you full retention of all historical 1-minute snapshots.

If new cloud data stops

Open the collector above, then Executions on the left. Look at recent scheduledCapture runs and their logs. Successful short runs outside collection hours are normal. Weekends and exchange holidays are skipped. Click Triggers (clock icon) to check that scheduledCapture exists and runs every minute. Google trigger failure notifications may help, but silence is not proof of health.

What remains automatic

Google retries transient capture failures and evening candle requests. The laptop task retries sync every ten minutes while you are signed in; the dashboard also syncs in the background. Cleanup preserves files when verification is missing. Collection continues with the laptop off, while Google/broker authorization, quota and storage remain available.

Turn the laptop on with Drive connected at least weekly and allow synchronization to finish. If it stays off for weeks, collection can continue but cleanup will wait and Drive usage grows. Keep an independent backup of the permanent local archive: a verification receipt cannot protect against later laptop disk failure.

Cannot self-repair: expired/revoked permissions, account restrictions, service outages, storage exhaustion, incompatible provider changes or lost local disks. For persistent code errors, share only the sanitized repair report and error text with technical support, never tokens.
