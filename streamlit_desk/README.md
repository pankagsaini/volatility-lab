# Compatibility launchers

Use `python -m volatility_lab` after installing the package. Add `--lan` for LAN access or `--port 8502` for another port.

These files remain thin wrappers. Startup implementation belongs in `volatility_lab/runtime`, presentation in `volatility_lab/ui`. For Streamlit Community Cloud use `streamlit_app.py`.

See [deployment](../handbook/deployment.md) and the [documentation index](../handbook/README.md).
